# MiMoQuant

MiMoQuant is a Python-based GUI application for automated quantification of mitochondria morphology. It provides a desktop interface for loading microscopy images, managing annotations, reviewing regions of interest, and supporting downstream analysis and reporting workflows.

This repository accompanies an academic journal paper. The source code will be published in this GitHub repository after the paper is accepted.
