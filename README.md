# MiMoQuant

MiMoQuant is a Python-based GUI application for automated quantification of mitochondria morphology. It provides a desktop interface for loading microscopy images, managing annotations, reviewing regions of interest, and supporting downstream analysis and reporting workflows.

This repository accompanies an academic journal paper. The manuscript abstract contains the address of this source repository, and peer reviewers have been given the information needed to evaluate the software and source code. The source code in this GitHub repository will be published after the paper is accepted.
